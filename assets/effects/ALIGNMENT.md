All 87 original images use a 496×496 transparent canvas. Numeric order, canvas scale and each set's existing alpha-union pivot are preserved. Reviewing ordered contact sheets shows deliberate travel and changing silhouettes; centering each image separately would erase that progression. Original PNG pixels and shared pivots were not changed.

These observations are a visual review, not proof that every source frame perfectly matches every authored weapon swing. No clearly accidental isolated placement jump was identified confidently enough to override the source coordinates. A sticker's artwork center also differs from the character's weapon pivot; placement/rotation still require authoring.

For a frame that looks wrong in context, select its numbered thumbnail and open **Image alignment**. Bright artwork is the selected image; faint artwork is its previous/next included neighbor in the same coordinates. Image X/Y adjust only that original image within this effect. Reset restores source alignment. Removing/restoring images preserves their corrections and original order. Original asset files, other effects and older single-image stickers are unaffected.
